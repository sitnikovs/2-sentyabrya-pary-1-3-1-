1. Название и описание задачи
Программа представляет собой мини-систему для работы с геометрическими фигурами. Реализован базовый класс Figure и два дочерних класса Circle и Square. Программа демонстрирует принципы объектно-ориентированного программирования: инкапсуляцию, наследование и полиморфизм. Основная задача — создание списка фигур разных типов и вычисление их общей площади через единый интерфейс.

2. Архитектура проекта
Инкапсуляция: координаты фигуры (__x, __y) и цвет (__color) скрыты в базовом классе Figure. Доступ к координатам осуществляется через публичные методы get_coords() и set_coords(). В дочерних классах скрыты специфичные свойства: __radius в Circle и __side в Square. Доступ к этим свойствам через геттеры и сеттеры get_radius(), set_radius(), get_side(), set_side().

Наследование: базовый класс Figure содержит общие свойства и методы. Circle и Square наследуют от Figure и расширяют его функциональность. В конструкторах дочерних классов вызывается super().init() для инициализации родительских атрибутов. Схема наследования: Figure -> Circle и Figure -> Square.

Полиморфизм: в обоих дочерних классах переопределен метод calculate_area(). Метод draw() также переопределен в каждом дочернем классе. В главной программе создается список фигур разных типов, и для каждой вызывается calculate_area() без проверки типа, что демонстрирует полиморфное поведение.

3. Пример использования
python
circle1 = Circle(5, 0, 0, "красный")
circle2 = Circle(3, 2, 3, "синий")
square1 = Square(4, -1, 1, "зеленый")
square2 = Square(6, 5, -2, "желтый")
circle3 = Circle(2, -3, 4, "фиолетовый")

figures = [circle1, circle2, square1, square2, circle3]

total_area = 0
for figure in figures:
    total_area += figure.calculate_area()
    figure.draw()

print(f"\nОбщая площадь всех фигур: {total_area:.2f}")
